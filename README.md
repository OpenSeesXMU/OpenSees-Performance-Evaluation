# Performance Assessment of OpenSees

This repository presents a performance assessment of **OpenSees** through several representative structural and geotechnical examples.

The study evaluates the **accuracy, computational performance, and nonlinear simulation capability** of OpenSees by comparing its numerical results with **Abaqus** and published **experimental data**.

The examples include:

- Static and dynamic analysis of a large-scale nuclear containment structure
- Nonlinear analysis of reinforced concrete frames
- Simulation of reinforced concrete components using Peridynamics
- Seismic liquefaction analysis of a soil slope

Overall, the study demonstrates the capability of OpenSees for large-scale finite element analysis, nonlinear structural simulation, and Peridynamics-based failure analysis.
